### 📰 News Intelligence Pipeline

**Pipeline de coleta e análise textual de notícias**

Projeto em Python que reúne etapas de coleta de notícias, limpeza e processamento de texto e exploração dos conteúdos em uma interface com Streamlit.

- Coleta de notícias de fontes disponíveis na web.
- Limpeza e processamento textual.
- Análise de frequência de palavras e exploração dos textos.
- Experimentação com análise de sentimentos.
- Apresentação de informações em dashboard.

**Tecnologias:** Python · Pandas · BeautifulSoup · Streamlit · TextBlob
